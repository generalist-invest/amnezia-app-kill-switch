# Amnezia App Kill Switch

Утилита для Windows 10/11, которая не даёт выбранным `.exe` выйти в интернет мимо указанного интерфейса Amnezia VPN.

## Как запустить

1. Установите обычный Python 3 для Windows (с компонентом Tkinter), если его ещё нет.
2. Запустите `Start-AmneziaAppKillSwitch.cmd` двойным щелчком и подтвердите запрос администратора.
3. Включите Amnezia VPN хотя бы один раз, чтобы её адаптер появился в списке.
4. Выберите **именно интерфейс Amnezia** — обычно в названии есть `Amnezia`, `Wintun`, `WireGuard` или `WG`.
5. Добавьте `.exe` программы, которые нельзя выпускать напрямую, и нажмите **«Включить защиту навсегда»**.

После первого включения утилита автоматически создаёт две задачи Windows: монитор запускается от SYSTEM при загрузке компьютера, а значок со щитом — в трее после входа в учётную запись. Окно настройки больше открывать не нужно. Двойной щелчок по значку в трее открывает настройки; правый щелчок позволяет запустить проверку правил вручную.

### Claude из Microsoft Store

Не пытайтесь выбирать `Claude.exe` вручную: Store скрывает его в защищённой папке `WindowsApps`, а путь меняется при обновлениях. Нажмите **«Добавить Claude (Store)»**. В списке появится `store:Claude_pzs8sxrjxfjjc`. При каждом применении утилита сама находит актуальный `Claude.exe` внутри текущей версии пакета и создаёт обычное правило брандмауэра для этого процесса.

## Несколько устройств

Папку с тремя файлами из этого пакета можно скопировать на любой Windows-компьютер и запустить там тем же способом. Чтобы не создавать список заново, на первом компьютере нажмите **«Экспорт настроек»**, скопируйте полученный JSON на другой и выберите **«Импорт настроек»**.

Импорт не включает защиту автоматически — это намеренно. Перед включением на новом устройстве проверьте выбранный адаптер Amnezia и пути к программам: имя VPN-интерфейса и место установки приложений могут отличаться.

## Что именно делает защита

Для каждой выбранной программы создаётся исходящее правило Windows Firewall на **каждый реальный IP-интерфейс**, кроме выбранного VPN-интерфейса. Поэтому при обрыве Amnezia Windows пытается отправить данные через Wi-Fi/Ethernet, а эти пути уже заблокированы. Служебные `6to4`, `Teredo`, `ISATAP` и loopback-интерфейсы не добавляются: Windows не позволяет надёжно привязывать к ним такие правила. Правила сохраняются после перезагрузки; фоновый монитор запускается от SYSTEM при старте Windows и каждые 3 секунды охватывает адаптеры, созданные позже.

Интернет остальных программ не затрагивается. Эта версия не устанавливает драйвер, службу или сетевой прокси и не передаёт никаких данных в сеть.

## Важные ограничения

- Выбранные приложения должны использовать собственный `.exe`. Если программа порождает другой сетевой процесс, добавьте и его `.exe`.
- Не выбирайте Wi-Fi/Ethernet как VPN-интерфейс: это фактически даст приложению прямой доступ. Перед включением убедитесь, что выбран адаптер Amnezia.
- Не выбирайте `6to4 Adapter`, `Teredo`, `ISATAP` или `Loopback`: это системные переходные адаптеры Windows, не VPN.
- Пока новые правила применяются, утилита выбирает безопасный режим: кратковременно может заблокироваться больше путей, но не появляется разрешённый обходной путь.
- «Отключить и удалить правила» полностью снимает защиту. Делайте это только когда это действительно нужно.

## Удаление

Откройте утилиту от администратора, нажмите «Отключить и удалить правила». Автозапуск при необходимости удаляется командой PowerShell от администратора:

```powershell
Unregister-ScheduledTask -TaskName 'Amnezia App Kill Switch' -Confirm:$false
```

Журнал и конфигурация хранятся в `C:\ProgramData\AmneziaAppKillSwitch`.
