# Amnezia App Kill Switch — Windows x64

Это автономная версия: Python устанавливать не нужно.

1. Скачайте и распакуйте ZIP на Windows 10/11 x64.
2. Щёлкните правой кнопкой `AmneziaAppKillSwitch.exe` и выберите **«Запуск от имени администратора»**.
3. Подключите Amnezia VPN, выберите её сетевой интерфейс и добавьте нужные приложения.
4. Нажмите **«Включить защиту навсегда»** один раз.

После этого правила хранятся в Windows Firewall. Фоновый монитор запускается при загрузке компьютера, а значок со щитом появляется в трее после входа в Windows. На других компьютерах этот процесс настройки нужно выполнить один раз: имя VPN-адаптера и путь к приложениям могут отличаться.

## Обновление

Запустите новую версию EXE от имени администратора и снова нажмите «Включить защиту навсегда». Она обновит свою рабочую копию в `C:\ProgramData\AmneziaAppKillSwitch`.

## Удаление

Откройте программу от имени администратора и нажмите «Отключить и удалить правила».
