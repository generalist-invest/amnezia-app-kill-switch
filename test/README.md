# Traffic Probe

Безопасная тестовая программа для проверки Amnezia App Kill Switch. Она ничего не делает при запуске. После нажатия кнопки выполняется один HTTPS-запрос к `https://example.com/`; в окне показывается только успех или ошибка.

## Проверка

1. Добавьте `TrafficProbe.exe` в Amnezia App Kill Switch и включите постоянную защиту.
2. При подключённой Amnezia откройте `TrafficProbe.exe` и нажмите «Проверить соединение»: ожидается «УСПЕХ».
3. Отключите Amnezia. Не выключая защиту, снова нажмите кнопку: ожидается «ЗАБЛОКИРОВАНО / недоступно».
4. Снова подключите Amnezia и убедитесь, что запрос опять проходит.

Если запрос не проходит и при подключённой Amnezia, это не считается успехом теста: нужно проверить выбранный VPN-интерфейс или правило утилиты.
